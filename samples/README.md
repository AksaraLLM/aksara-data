# Sample Data

Small, concrete example files showing the exact JSONL format each pipeline
stage expects — so you have something real to point commands at instead of
guessing at a format from a placeholder path. Replace these with real
bulk data before training anything serious; they're demonstration-sized
(a handful of records each), not real training sets.

| File | Format | Used by |
|---|---|---|
| `corpus_sample/wiki_sample.jsonl` | `{"text": "..."}` | Tokenizer training (`aksara-tokenizer`), pre-training (`aksaraLLM/train.py`, `aksara-train/pretrain.py`) |
| `sft_sample.jsonl` | `{"instruction": "...", "input": "...", "output": "..."}` | Instruction-tuning (`aksaraLLM/sft.py`) |
| `dpo_sample.jsonl` | `{"chosen": "...", "rejected": "..."}` (each a full `### Instruksi:` / `### Jawaban:` formatted string) | Alignment (`aksaraLLM/dpo.py`) |

See `../generators/identity_core.jsonl` (generated by `generators/identity_core.py`)
for identity + core Indonesian knowledge seed data in the same `instruction`/`output`
format as `sft_sample.jsonl` — meant to be concatenated into your real SFT
dataset, not used standalone. See `../datasheets/MODEL_DATASHEET.md` for
what it contains and the recommended training weight per category.
